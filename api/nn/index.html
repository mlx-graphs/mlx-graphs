Neural Networks#

Linear(input_dims, output_dims[, bias])

Linear layer with Xavier Glorot weight initialization and a zero bias.

HeteroDictLinear(input_dims, output_dims[, bias])

Applies a separate linear layer to each node type.

MessagePassing([aggr, aggr_kwargs])

Base class for creating Message Passing Neural Networks (MPNNs) [1].

GraphNetworkBlock([node_model, edge_model, ...])

Implements a generic Graph Network block as defined in [1].

Convolution layers#

GCNConv(node_features_dim, out_features_dim)

Graph convolution layer from "Semi-Supervised Classification with Graph Convolutional Networks" paper.

SAGEConv(node_features_dim, out_features_dim)

GraphSAGE convolution layer from "Inductive Representation Learning on Large Graphs" paper.

GINConv(mlp[, eps, learn_eps, ...])

Graph Isomorphism Network convolution layer from "How Powerful are Graph Neural Networks?" paper.

GATConv(node_features_dim, out_features_dim)

Graph Attention Network convolution layer from "Graph Attention Networks" paper.

GATv2Conv(node_features_dim, out_features_dim)

Graph Attention Network convolution layer with dynamic attention.

TransformerConv(node_features_dim, ...[, ...])

Graph transformer convolution layer from "Masked Label Prediction: Unified Message Passing Model for Semi-Supervised Classification" paper.

GraphConv(node_features_dim, out_features_dim)

Graph convolution layer from "Weisfeiler and Leman Go Neural: Higher-order Graph Neural Networks" paper.

SGConv(node_features_dim, out_features_dim)

Simple graph convolution layer from "Simplifying Graph Convolutional Networks" paper.

APPNP(K, alpha[, dropout, add_self_loops])

Approximate personalized propagation of neural predictions layer from "Predict then Propagate: Graph Neural Networks meet Personalized PageRank" paper.

ChebConv(node_features_dim, out_features_dim, K)

Chebyshev spectral graph convolution layer from "Convolutional Neural Networks on Graphs with Fast Localized Spectral Filtering" paper.

TAGConv(node_features_dim, out_features_dim)

Topology adaptive graph convolution layer from "Topology Adaptive Graph Convolutional Networks" paper.

EdgeConv(mlp, **kwargs)

Edge convolution layer from "Dynamic Graph CNN for Learning on Point Clouds" paper.

RGCNConv(node_features_dim, ...[, ...])

Relational graph convolution layer from "Modeling Relational Data with Graph Convolutional Networks" paper.

FastRGCNConv(node_features_dim, ...[, ...])

RGATConv(node_features_dim, ...[, ...])

The relational graph attentional operator from the "Relational Graph Attention Networks" paper.

GENConv(node_features_dim, out_features_dim)

The GENeralized Graph Convolution (GENConv) from the "DeeperGCN: All You Need to Train Deeper GCNs" paper.

MixHopConv(node_features_dim, out_features_dim)

The Mix-Hop graph convolutional operator from the "MixHop: Higher-Order Graph Convolutional Architectures via Sparsified Neighborhood Mixing" paper.

FAConv(node_features_dim[, eps, dropout, ...])

The Frequency Adaptive Graph Convolution operator from the "Beyond Low-Frequency Information in Graph Convolutional Networks" paper.

GeneralConv(node_features_dim, out_features_dim)

A general GNN layer adapted from the "Design Space for Graph Neural Networks" paper.

DirGNNConv(conv[, alpha, root_weight, ...])

A generic wrapper for computing graph convolution on directed graphs as described in the "Edge Directionality Improves Learning on Heterophilic Graphs" paper.

HANConv(node_features_dim, out_features_dim, ...)

The Heterogeneous Graph Attention Operator from the "Heterogenous Graph Attention Network" paper.

HGTConv(node_features_dim, out_features_dim, ...)

The Heterogeneous Graph Transformer (HGT) operator from the "Heterogeneous Graph Transformer" paper.

SimpleConv([aggr, combine_root_func])

A simple non-trainable message passing layer.

HeteroConv(convs[, aggr])

Wrapper that runs one graph convolution per edge type of a heterogeneous graph and combines the results per destination node type.

GeneralizedRelationalConv(in_features_dim, ...)

Generalized relational convolution layer from Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction paper.

GINEConv(mlp[, eps, learn_eps, ...])

Graph Isomorphism Network convolution with edge features, from the "Strategies for Pre-training Graph Neural Networks" paper.

GCN2Conv(node_features_dim, alpha[, theta, ...])

Graph convolution with initial residual connections and identity mapping (GCNII) from the "Simple and Deep Graph Convolutional Networks" paper.

SSGConv(node_features_dim, out_features_dim, ...)

Simple spectral graph convolution layer from "Simple Spectral Graph Convolution" paper.

LGConv([normalize])

Light graph convolution from the "LightGCN: Simplifying and Powering Graph Convolution Network for Recommendation" paper.

ARMAConv(node_features_dim, out_features_dim)

ARMA graph convolution layer from the "Graph Neural Networks with Convolutional ARMA Filters" paper.

GatedGraphConv(out_features_dim, num_layers)

Gated graph convolution layer from the "Gated Graph Sequence Neural Networks" paper.

ResGatedGraphConv(node_features_dim, ...[, ...])

Residual gated graph convolution layer from the "Residual Gated Graph ConvNets" paper.

NNConv(node_features_dim, out_features_dim, mlp)

Edge-conditioned convolution layer from the "Neural Message Passing for Quantum Chemistry" paper (also known as ECConv, from "Dynamic Edge-Conditioned Filters in Convolutional Neural Networks on Graphs").

CGConv(node_features_dim[, ...])

Crystal graph convolution layer from the "Crystal Graph Convolutional Neural Networks for an Accurate and Interpretable Prediction of Material Properties" paper.

MFConv(node_features_dim, out_features_dim)

Graph convolution layer from the "Convolutional Networks on Graphs for Learning Molecular Fingerprints" paper.

LEConv(node_features_dim, out_features_dim)

Local extremum graph convolution layer from the "ASAP: Adaptive Structure Aware Pooling for Learning Hierarchical Graph Representations" paper.

FiLMConv(node_features_dim, out_features_dim)

Feature-wise linear modulation (FiLM) graph convolution layer from the "GNN-FiLM: Graph Neural Networks with Feature-wise Linear Modulation" paper.

AGNNConv([requires_grad, add_self_loops])

Graph attentional propagation layer from the "Attention-based Graph Neural Network for Semi-Supervised Learning" paper.

ClusterGCNConv(node_features_dim, ...[, ...])

Graph convolution layer from the "Cluster-GCN: An Efficient Algorithm for Training Deep and Large Graph Convolutional Networks" paper.

DynamicEdgeConv(mlp, k, **kwargs)

PNAConv(node_features_dim, out_features_dim, ...)

Principal Neighbourhood Aggregation graph convolution from "Principal Neighbourhood Aggregation for Graph Nets" paper.

GPSConv(channels, conv[, heads, dropout, ...])

The general, powerful, scalable (GPS) graph transformer layer from the "Recipe for a General, Powerful, Scalable Graph Transformer" paper, as PyG's GPSConv.

Fused message passing#

Layers decorated with fused_message_passing() aggregate neighbours with a single sparse-dense matmul (SpMM) from mlx-cluster instead of gather-scatter, so the [num_edges, features] message array is never created. GCNConv, SAGEConv, GINConv, GATConv, GATv2Conv, GraphConv, SGConv, APPNP, ChebConv, TAGConv and SimpleConv use it out of the box (the attention layers aggregate with one SpMM per head). Layers whose messages can’t be fused (e.g. GINE with edge features) fall back to gather-scatter automatically.

The default format="auto" starts with the COO kernel and switches to the faster, deterministic CSR kernel once converting the graph pays off: right away for graphs with a million edges or more, and after a few calls on the same edge_index otherwise (e.g. full-batch training). Conversions are cached by edge_index identity; call clear_csr_cache() after modifying an edge_index in place.

import mlx_graphs.nn as gnn

# Turn it off globally, or force a format for every layer
gnn.set_fused_message_passing(True, format="csr")

# Or only for a block of code (handy for comparing both paths)
with gnn.fused_message_passing_mode(False):
    reference = model(edge_index, x)

Heterogeneous models#

to_hetero() converts a homogeneous model (e.g. a GraphSAGE, or a model written with message passing layers, Linear layers and activations) into a heterogeneous one, with one copy of every message passing layer per edge type and of every other layer per node type, like PyG’s to_hetero. The converted model takes dicts keyed by node and edge types.

from mlx_graphs.nn import GraphSAGE, to_hetero

model = to_hetero(
    GraphSAGE(64, 64, num_layers=2, out_features_dim=4),
    data.metadata(),
    input_dims=data.num_node_features,  # no lazy sizes in MLX
)
out = model(data.edge_index_dict, data.node_features_dict)

Neural networks¶

Layers, models, aggregations, normalization and pooling of mlx_graphs.nn, under the names of torch_geometric.nn.

Building blocks¶

Class Description
Linear Linear layer with Xavier Glorot weight initialization and a zero bias.
HeteroDictLinear Applies a separate linear layer to each node type.
MessagePassing Base class for creating Message Passing Neural Networks (MPNNs) [1].
GraphNetworkBlock Implements a generic Graph Network block as defined in [1].

Convolution layers¶

Class Description
GCNConv Graph convolution layer from "Semi-Supervised Classification with Graph Convolutional Networks" paper.
SAGEConv GraphSAGE convolution layer from "Inductive Representation Learning on Large Graphs" paper.
GINConv Graph Isomorphism Network convolution layer from "How Powerful are Graph Neural Networks?" paper.
GATConv Graph Attention Network convolution layer from "Graph Attention Networks" paper.
GATv2Conv Graph Attention Network convolution layer with dynamic attention.
TransformerConv Graph transformer convolution layer from "Masked Label Prediction: Unified Message Passing Model for Semi-Supervised Classification" paper.
GraphConv Graph convolution layer from "Weisfeiler and Leman Go Neural: Higher-order Graph Neural Networks" paper.
SGConv Simple graph convolution layer from "Simplifying Graph Convolutional Networks" paper.
APPNP Approximate personalized propagation of neural predictions layer from "Predict then Propagate: Graph Neural Networks meet Personalized PageRank" paper.
ChebConv Chebyshev spectral graph convolution layer from "Convolutional Neural Networks on Graphs with Fast Localized Spectral Filtering" paper.
TAGConv Topology adaptive graph convolution layer from "Topology Adaptive Graph Convolutional Networks" paper.
EdgeConv Edge convolution layer from "Dynamic Graph CNN for Learning on Point Clouds" paper.
RGCNConv Relational graph convolution layer from "Modeling Relational Data with Graph Convolutional Networks" paper.
FastRGCNConv Relational graph convolution layer with the same semantics as RGCNConv, from the "Modeling Relational Data with Graph Convolutional Networks" paper.
RGATConv The relational graph attentional operator from the "Relational Graph Attention Networks" paper.
GENConv The GENeralized Graph Convolution (GENConv) from the "DeeperGCN: All You Need to Train Deeper GCNs" paper.
MixHopConv The Mix-Hop graph convolutional operator from the "MixHop: Higher-Order Graph Convolutional Architectures via Sparsified Neighborhood Mixing" paper.
FAConv The Frequency Adaptive Graph Convolution operator from the "Beyond Low-Frequency Information in Graph Convolutional Networks" paper.
GeneralConv A general GNN layer adapted from the "Design Space for Graph Neural Networks" paper.
DirGNNConv A generic wrapper for computing graph convolution on directed graphs as described in the "Edge Directionality Improves Learning on Heterophilic Graphs" paper.
HANConv The Heterogeneous Graph Attention Operator from the "Heterogenous Graph Attention Network" paper.
HGTConv The Heterogeneous Graph Transformer (HGT) operator from the "Heterogeneous Graph Transformer" paper.
SimpleConv A simple non-trainable message passing layer.
HeteroConv Wrapper that runs one graph convolution per edge type of a heterogeneous graph and combines the results per destination node type.
GeneralizedRelationalConv Generalized relational convolution layer from Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction paper.
GINEConv Graph Isomorphism Network convolution with edge features, from the "Strategies for Pre-training Graph Neural Networks" paper.
GCN2Conv Graph convolution with initial residual connections and identity mapping (GCNII) from the "Simple and Deep Graph Convolutional Networks" paper.
SSGConv Simple spectral graph convolution layer from "Simple Spectral Graph Convolution" paper.
LGConv Light graph convolution from the "LightGCN: Simplifying and Powering Graph Convolution Network for Recommendation" paper.
ARMAConv ARMA graph convolution layer from the "Graph Neural Networks with Convolutional ARMA Filters" paper.
GatedGraphConv Gated graph convolution layer from the "Gated Graph Sequence Neural Networks" paper.
ResGatedGraphConv Residual gated graph convolution layer from the "Residual Gated Graph ConvNets" paper.
NNConv Edge-conditioned convolution layer from the "Neural Message Passing for Quantum Chemistry" paper (also known as ECConv, from "Dynamic Edge-Conditioned Filters in Convolutional Neural Networks on Graphs").
CGConv Crystal graph convolution layer from the "Crystal Graph Convolutional Neural Networks for an Accurate and Interpretable Prediction of Material Properties" paper.
MFConv Graph convolution layer from the "Convolutional Networks on Graphs for Learning Molecular Fingerprints" paper.
LEConv Local extremum graph convolution layer from the "ASAP: Adaptive Structure Aware Pooling for Learning Hierarchical Graph Representations" paper.
FiLMConv Feature-wise linear modulation (FiLM) graph convolution layer from the "GNN-FiLM: Graph Neural Networks with Feature-wise Linear Modulation" paper.
AGNNConv Graph attentional propagation layer from the "Attention-based Graph Neural Network for Semi-Supervised Learning" paper.
ClusterGCNConv Graph convolution layer from the "Cluster-GCN: An Efficient Algorithm for Training Deep and Large Graph Convolutional Networks" paper.
DynamicEdgeConv Dynamic edge convolution layer from the "Dynamic Graph CNN for Learning on Point Clouds" paper (see EdgeConv), where the graph is dynamically constructed using the nearest neighbors in the feature space.
PNAConv Principal Neighbourhood Aggregation graph convolution from "Principal Neighbourhood Aggregation for Graph Nets" paper.
GPSConv The general, powerful, scalable (GPS) graph transformer layer from the "Recipe for a General, Powerful, Scalable Graph Transformer" paper, as PyG's GPSConv.

Point cloud and mesh layers¶

Layers for point clouds and meshes, which take node positions pos (and normals or pseudo-coordinates), e.g. from ModelNet with SamplePoints. PointConv is an alias of PointNetConv.

Class Description
PointNetConv The PointNet set layer from the "PointNet: Deep Learning on Point Sets for 3D Classification and Segmentation" and "PointNet++: Deep Hierarchical Feature Learning on Point Sets in a Metric Space" papers.
PointTransformerConv The Point Transformer layer from the "Point Transformer" paper.
PPFConv The PPFNet operator from the "PPFNet: Global Context Aware Local Features for Robust 3D Point Matching" paper.
XConv The convolutional operator on \(\mathcal{X}\)-transformed points from the "PointCNN: Convolution On X-Transformed Points" paper.
SplineConv The spline-based convolutional operator from the "SplineCNN: Fast Geometric Deep Learning with Continuous B-Spline Kernels" paper.
GMMConv The Gaussian mixture model convolutional operator from the "Geometric Deep Learning on Graphs and Manifolds using Mixture Model CNNs" paper.
FeaStConv The (translation-invariant) feature-steered convolutional operator from the "FeaStNet: Feature-Steered Graph Convolutions for 3D Shape Analysis" paper.

Dense convolution layers¶

Layers on batched dense adjacency matrices [batch_size, num_nodes, num_nodes] (e.g. from to_dense_adj or a DenseDataLoader), called as conv(adj, node_features, mask).

Class Description
DenseGCNConv Dense version of GCNConv.
DenseSAGEConv Dense version of SAGEConv (mean aggregation).
DenseGINConv Dense version of GINConv.
DenseGraphConv Dense version of GraphConv.

Models¶

Ready-to-use multi-layer models, with optional normalization, dropout and Jumping Knowledge.

Class Description
GCN Graph Convolutional Network from "Semi-Supervised Classification with Graph Convolutional Networks", a stack of GCNConv layers.
GraphSAGE GraphSAGE from "Inductive Representation Learning on Large Graphs", a stack of SAGEConv layers.
GIN Graph Isomorphism Network from "How Powerful are Graph Neural Networks?", a stack of GINConv layers, each with a two-layer MLP.
GAT Graph Attention Network from "Graph Attention Networks" (or, with v2=True, "How Attentive are Graph Attention Networks?"), a stack of GATConv / GATv2Conv layers.
MLP Multi-layer perceptron.
BasicGNN Base class of the ready-to-use GNN models.
PNA Principal Neighbourhood Aggregation network from "Principal Neighbourhood Aggregation for Graph Nets", a stack of PNAConv layers.

Other models and building blocks:

Class Description
EdgeCNN The Dynamic Graph CNN model from the "Dynamic Graph CNN for Learning on Point Clouds" paper, a stack of EdgeConv layers, each with a two-layer MLP mapping 2 * in_dim features to out_dim.
LINKX The LINKX model from the "Large Scale Learning on Non-Homophilous Graphs: New Benchmarks and Strong Simple Methods" paper.
DeepGCNLayer The skip connection operations from the "DeepGCNs: Can GCNs Go as Deep as CNNs?" and "All You Need to Train Deeper GCNs" papers.
MaskLabel The label embedding and masking layer from the "Masked Label Prediction: Unified Message Passing Model for Semi-Supervised Classification" paper.
RECT_L The RECT model, i.e. its supervised RECT-L part, from the "Network Embedding with Completely-imbalanced Labels" paper.
DeepGraphInfomax The Deep Graph Infomax model from the "Deep Graph Infomax" paper, based on a user-defined encoder \(\mathcal{E}\), summary (readout) function \(\mathcal{R}\) and corruption function \(\mathcal{C}\).
LightGCN The LightGCN model from the "LightGCN: Simplifying and Powering Graph Convolution Network for Recommendation" paper.
SGFormer The SGFormer model from the "SGFormer: Simplifying and Empowering Transformers for Large-Graph Representations" paper, as PyG's SGFormer.
Polynormer The Polynormer model from the "Polynormer: Polynomial-Expressive Graph Transformer in Linear Time" paper, as PyG's Polynormer.

Molecular and 3D models¶

Models for molecules, on atom types and 3D positions pos (SchNet, DimeNet, DimeNetPlusPlus) or on the atom and bond features of from_smiles (AttentiveFP), e.g. on QM9 or MoleculeNet.

Class Description
SchNet The continuous-filter convolutional neural network SchNet from the "SchNet: A Continuous-filter Convolutional Neural Network for Modeling Quantum Interactions" paper, with interaction blocks of the form
DimeNet The directional message passing neural network (DimeNet) from the "Directional Message Passing for Molecular Graphs" paper.
DimeNetPlusPlus DimeNet++ from the "Fast and Uncertainty-Aware Directional Message Passing for Non-Equilibrium Molecules" paper.
AttentiveFP The Attentive FP model for molecular representation learning from the "Pushing the Boundaries of Molecular Representation for Drug Discovery with the Graph Attention Mechanism" paper, based on graph attention mechanisms.

Normalization¶

Class Description
BatchNormalization Applies batch normalization over a batch of features as described in the Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift" paper.
HeteroBatchNormalization Applies batch normalization over a batch of heterogeneous features, as described in the "Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift" paper.
InstanceNormalization Instance normalization over each individual example in batch of node features as described in the paper Instance Normalization: The Missing Ingredient for Fast Stylization paper.
LayerNormalization Applies layer normalization over each individual example in a batch of features as described in the Layer Normalization paper.
HeteroLayerNormalization Applies layer normalization over each individual example in a batch of heterogeneous features, as described in the "Layer Normalization" paper.
GraphNormalization Applies graph normalization over individual graphs as described in the "GraphNorm: A Principled Approach to Accelerating Graph Neural Network Training" paper.
PairNormalization Applies pair normalization over node features as described in the "PairNorm: Tackling Oversmoothing in GNNs" paper.
GraphSizeNormalization Applies graph size normalization over each individual graph in a batch of node features as described in the "Benchmarking Graph Neural Networks" paper.
MeanSubtractionNormalization Applies layer normalization by subtracting the mean from the inputs as described in the "Revisiting 'Over-smoothing' in Deep GCNs" paper.
MessageNormalization Applies message normalization over the aggregated messages as described in the "DeeperGCNs: All You Need to Train Deeper GCNs" paper.
DiffGroupNormalization The differentiable group normalization layer from the "Towards Deeper Graph Neural Networks with Differentiable Group Normalization" paper, which normalizes node features group-wise via a learnable soft cluster assignment.

Pooling and readout¶

Class Description
JumpingKnowledge Jumping Knowledge layer aggregation from "Representation Learning on Graphs with Jumping Knowledge Networks" paper.
AttentionalAggregation Soft attention pooling (global attention) from "Gated Graph Sequence Neural Networks" paper.
Set2Set Set2Set global pooling from "Order Matters: Sequence to Sequence for Sets" paper.
TopKPooling \(\mathrm{top}_k\) pooling operator from the "Graph U-Nets", "Towards Sparse Hierarchical Graph Classifiers" and "Understanding Attention and Generalization in Graph Neural Networks" papers.
SAGPooling The self-attention pooling operator from the "Self-Attention Graph Pooling" and "Understanding Attention and Generalization in Graph Neural Networks" papers.
Function Description
global_add_pool() Sums all node features to obtain a global graph-level representation.
global_mean_pool() Takes the feature-wise mean value along all node features to obtain a global graph-level representation.
global_max_pool() Takes the feature-wise maximum value along all node features to obtain a global graph-level representation.
global_sort_pool() The global pooling operator from the "An End-to-End Deep Learning Architecture for Graph Classification" paper.
topk() Selects the nodes with the highest scores in each graph.
filter_adj() Keeps the edges between the nodes perm, relabeled by their position in perm.
knn() Finds for each point of y the k nearest points of x.
knn_graph() Computes the graph connecting each point to its k nearest points.
radius() Finds for each point of y the points of x within distance r.
radius_graph() Computes the graph connecting each point to the points within distance r.

Point cloud sampling and cluster pooling (fps, voxel_grid, graclus and nearest are also in mlx_graphs.utils):

Function Description
fps() Farthest point sampling, from the "PointNet++: Deep Hierarchical Feature Learning on Point Sets in a Metric Space" paper.
voxel_grid() Voxel grid pooling from the "Dynamic Edge-Conditioned Filters in Convolutional Networks on Graphs" paper: overlays a regular grid of user-defined size over a point cloud and clusters all the points within the same voxel.

Fused message passing¶

Layers decorated with fused_message_passing() aggregate neighbours with a single sparse-dense matmul (SpMM) from mlx-cluster instead of gather-scatter, so the [num_edges, features] message array is never created. GCNConv, SAGEConv, GINConv, GATConv, GATv2Conv, GraphConv, SGConv, APPNP, ChebConv, TAGConv and SimpleConv use it out of the box (the attention layers aggregate with one SpMM per head). Layers whose messages can't be fused (e.g. GINE with edge features) fall back to gather-scatter automatically.

The default format="auto" starts with the COO kernel and switches to the faster, deterministic CSR kernel once converting the graph pays off: right away for graphs with a million edges or more, and after a few calls on the same edge_index otherwise (e.g. full-batch training). Conversions are cached by edge_index identity; call clear_csr_cache() after modifying an edge_index in place.

import mlx_graphs.nn as gnn

# Turn it off globally, or force a format for every layer
gnn.set_fused_message_passing(True, format="csr")

# Or only for a block of code (handy for comparing both paths)
with gnn.fused_message_passing_mode(False):
    reference = model(edge_index, x)
Function Description
fused_message_passing() Class decorator: lets a MessagePassing layer fuse message and aggregate into a single sparse x dense matmul (SpMM).
set_fused_message_passing() Globally enables/disables fused message passing.
fused_message_passing_mode() Context manager version of set_fused_message_passing().
is_fused_message_passing_enabled() Whether fused message passing is enabled and the kernels are available.
clear_csr_cache() Drops all cached CSR conversions used by the "auto" and "csr" formats of fused message passing.
gcn_norm() Symmetric GCN normalization of a graph.
clear_norm_cache() Drops the cached graph normalizations.

Heterogeneous models¶

to_hetero() converts a homogeneous model (e.g. a GraphSAGE, or a model written with message passing layers, Linear layers and activations) into a heterogeneous one, with one copy of every message passing layer per edge type and of every other layer per node type, like PyG's to_hetero. The converted model takes dicts keyed by node and edge types.

from mlx_graphs.nn import GraphSAGE, to_hetero

model = to_hetero(
    GraphSAGE(64, 64, num_layers=2, out_features_dim=4),
    data.metadata(),
    input_dims=data.num_node_features,  # no lazy sizes in MLX
)
out = model(data.edge_index_dict, data.node_features_dict)
Name Description
to_hetero() Conversion of homogeneous GNN models into heterogeneous ones (to_hetero).
to_hetero_with_bases() Converts a homogeneous GNN model into its heterogeneous equivalent via the basis-decomposition technique of the "Modeling Relational Data with Graph Convolutional Networks" paper (PyG's to_hetero_with_bases).
ToHeteroModel Heterogeneous version of a homogeneous model, returned by to_hetero().

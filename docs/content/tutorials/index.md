# Tutorials

Jupyter notebooks that build and train complete models with mlx-graphs, most
of them side by side with PyTorch Geometric on accuracy and runtime. Each page
shows the notebook with the outputs of its last run; download it to run it
yourself. New to mlx-graphs? Start with the [Quickstart](../getting-started/quickstart.md).

## Example scripts

The [`examples/`](https://github.com/mlx-graphs/mlx-graphs/tree/main/examples)
folder of the repository has runnable scripts that train models end to end
from the command line: node classification, GCN and GAT on Cora, link
prediction, heterogeneous GraphSAGE, TGN, GPS and more.
[See all the example scripts](examples.md).

Benchmarks
==========

MLX-graphs is compared with `PyTorch Geometric <https://pyg.org>`_ (PyG) on the
same Mac, on both PyTorch backends: MPS (the Apple GPU) and CPU.

The scripts are in
`benchmarks/pyg_comparison <https://github.com/mlx-graphs/mlx-graphs/tree/main/benchmarks/pyg_comparison>`_.
Its README describes what is measured and how the comparison is kept fair.

Each section below is one machine, with a figure and a table of the results.
